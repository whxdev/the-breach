# The Breach — an ai-excited-01 entry

Draws the whole image procedurally in code — no assets, no textures, just seeded vector work rasterised to a flat 1024×1024 PNG.
Fully deterministic: the same PRNG seed always yields byte-identical output.
Run it with `MAKEFUN_OUTPUT_DIR=out node main.ts` (writes `out/entry.png`).
